On this page, you'll find important information about Urth's maps, how they're made, and some helpful tools.

Measuring Areas

The easiest way to measure area is to use GIMP's Fuzzy Select tool in combination with the Histogram window (Windows > Dockable Dialogues > Histogram). The window displays the number of selected pixels at the bottom, which can then be multiplied by one of the area values below.

  • A pixel on the map is equivalent to 6.34126 km² (exactly 50 ÷ 2.808²)
  • The side of a pixel on the map is 2.518 km long (exactly √50 ÷ 2.808)
